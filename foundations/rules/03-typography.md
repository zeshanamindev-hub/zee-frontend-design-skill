# 03 · Typography rules (T1–T12)
Font catalogue, pairings and licences: `../typography.md`.

| ID | Rule | How to apply (numbers) | When | Honest caveat |
|---|---|---|---|---|
| **T1** | **Typography hierarchy** | Define 5–7 roles before designing: display, H1, H2, H3, body, small/meta, label. Each role differs from its neighbour by ≥ 1 scale step **and** ≥ 1 other property (weight, case, colour). | Always | More than 7 roles = noise. |
| **T2** | **Type scale** | Pick one ratio: 1.125–1.2 (dense UI, dashboards), 1.25 (SaaS/marketing), 1.333 (editorial), 1.414–1.5 (posters, expressive heroes). Base 16px web body; 17–18px for reading-heavy pages. | Always | Fluid type (R3) blends two scales across breakpoints; that's fine. |
| **T3** | **Modular scale** | Sizes = base × ratioⁿ (e.g. 16 · 20 · 25 · 31 · 39 · 49 · 61 at 1.25). Round to whole px; snap line-heights to the 4-pt grid. | Systems, tokens | Mathematical purity isn't the goal; nudge sizes that look wrong optically. |
| **T4** | **Golden-ratio typography** | Ratio 1.618 (16 → 26 → 42 → 68). Line-height ≈ 1.6 for body is sometimes attributed to φ. | Posters, hero display moments | **[Evidence: weak]** No special readability benefit; the jumps are too big for UI hierarchies. |
| **T5** | **Font pairing** | Max **2 families** (+ an optional mono). Pair by contrast of *structure* (serif display + sans text, or geometric display + humanist text) and similarity of *proportion* (x-height, width). Or use one superfamily with optical sizes. Always show **3 font options** with reasons (see `../typography.md` §8). | Brand set-up | Three families is almost always one too many. |
| **T6** | **Line height (leading)** | Body **1.45–1.65**; UI labels 1.2–1.4; headings **1.0–1.2** (tighter as size grows); all-caps labels 1.0–1.2. Longer lines need more leading. | Always | Figma's typography guide gives 1.125–1.2 as a general rule. That fits headings and display, not body copy, and WCAG 1.4.12 requires layouts to survive users setting 1.5. [Source: figma.com/resource-library/typography-in-design] |
| **T7** | **Line length (measure)** | Body **45–75 characters** (ideal ~60–66); use `max-width: 65ch`. Figma suggests 40–60 for English. Mobile 30–50 is acceptable. | Long-form text | `ch` depends on the font's "0" width; check visually. |
| **T8** | **Contrast in typography** | Create contrast with size (≥ 1.5× jumps between levels), weight (400 vs 700+, not 400 vs 500), case, colour (ink vs muted), and style (serif display vs sans body). | Hierarchy | Low-contrast weight pairs (500/600) look like mistakes. |
| **T9** | **Readability** | Body ≥ 16px; left-aligned (centre only headings & short quotes); avoid justified text on the web (rivers) unless hyphenation is on; no widows/orphans in headings (`text-wrap: balance` on headings, `pretty` on paragraphs). | Reading | `text-wrap` support: Baseline for `balance`; `pretty` is newer, so treat it as progressive enhancement. |
| **T10** | **Legibility** | Choose faces with open counters, clear I/l/1 and 0/O distinction, generous x-height for small sizes; avoid weights < 300 for text; light text on dark: add 0.01–0.02em tracking and +5–10% size. | Small text, UI, dark mode | Display faces can sacrifice legibility at large sizes only. |
| **T11** | **Typography consistency** | All text uses the token scale (no one-off sizes); same role = same style on every page; max 3 weights per family in production. | Systems | Exceptions (one editorial hero moment) must be written into the style guide. |
| **T12** | **Emphasis (pop / un-pop)** | Emphasise with size, weight, contrast, uppercase + tracking (+0.04–0.12em on small caps labels) or space. De-emphasise with lower contrast, smaller size, regular weight. Only page titles get every "pop" at once. For hover/selected states, change colour, background or underline, **not size or weight** (reflow). Avoid underline for anything that isn't a link. | Every text block | [Source: learnui.design, E. Kennedy, "7 Rules for Creating Gorgeous UI", 2024 update, rule 5] |
