# 01 · Color design rules (C1–C12)
Implementation details (OKLCH, tokens, dark mode) live in `../color-system.md`. Scheme decision procedure: `../color-system.md` §7. Niche palettes: `../niche-design-profiles.md`.

| ID | Rule | How to apply (numbers) | When | Honest caveat |
|---|---|---|---|---|
| **C1** | **60-30-10** | 60% dominant (usually a neutral surface), 30% secondary (surfaces, sections, type colour), 10% accent (primary CTA, key links, focus, one highlight). Measure by *area per viewport*, not per page. Mono brands: 60 light / 30 dark / 10 = **one inverted band or one texture** (see `palette.py --mono`). | Every UI | It's a starting ratio, not a law. Editorial and dark cinematic sites often run 80/15/5. Variants: 70/20/10 for calmer SaaS. |
| **C2** | **Colour harmony** | Choose a relationship on the wheel (C4–C8) and build it in **OKLCH** so lightness stays even (`scripts/palette.py`). Keep UI chrome to 1 hue + neutrals; spend harmonies on illustration, data and campaign moments. | Brand building, illustration | "Harmonious" ≠ usable; still run C9. [Expert] |
| **C3** | **Colour psychology** | Use as a *tie-breaker* after brand, category conventions and competitors. Typical associations: blue trust/calm, green growth/health, red urgency/appetite, orange energy/affordability, purple creativity/premium, black luxury/authority, earth tones natural/artisanal. | Niche/mood alignment | **[Evidence: weak/mixed]** Associations vary by culture, context and personal history. Never justify a palette *only* by psychology. |
| **C4** | **Complementary** | Base hue + 180°. Use the complement **only for the 10% accent** or for a single focal element; desaturate one side. | Need maximum pop for a CTA | Two saturated complements at equal area vibrate and fatigue the eye. |
| **C5** | **Analogous** | Base ± 30° (3 neighbours). One dominant, one support, one accent. | Calm, natural, cohesive brands (wellness, food, travel) | Low hue contrast, so hierarchy must come from **lightness** (C9) and weight. |
| **C6** | **Triadic** | Base +120° +240°. One hue leads; the other two at ≤ 10% each, often desaturated. | Playful, kids, education, illustration systems | Hard to keep premium; easily looks "toy". |
| **C7** | **Split-complementary** | Base +150° +210°. Softer than complementary with similar contrast. | Brands that need energy without clash | Still needs a clear dominant (C1). |
| **C8** | **Monochromatic** | One hue, many lightness steps (50–950 scale). Accent = the most saturated step or an inversion. For true black/white brands, hierarchy comes from value, weight, scale, space and texture (Direction D13). | Luxury, editorial, portfolios, B&W brands | Can feel flat. Add one contrast device (inversion band, photo, texture). |
| **C9** | **Contrast ratio** | WCAG 2.2: text ≥ **4.5:1**; large text (≥ 24px, or ≥ 18.66px bold) ≥ **3:1**; UI component boundaries & focus indicators ≥ **3:1** against adjacent colours. Check every token pair with `scripts/contrast.py`. | Always | WCAG 2 ratios are imperfect for dark mode and thin fonts. Use APCA as a second opinion, but legal conformance is still WCAG 2.x. |
| **C10** | **Warm vs cool** | Warm (red-orange-yellow) advances and energises; cool (blue-green-violet) recedes and calms. Use warm for the accent on a cool base (or the reverse) to separate action from surface. Tint neutrals slightly toward the brand temperature (OKLCH chroma 0.005–0.02). | Building depth and focus | Perceived temperature shifts with surroundings (simultaneous contrast). |
| **C11** | **Semantic colours** | Reserve hues for meaning: error (red), success (green), warning (amber), info (blue). Never reuse the error red as the brand accent on the same screen. Each state = colour + icon + text. | Forms, dashboards, status | Cultural meaning varies (red = luck/prosperity in China). [Source: uxdesign.cc 58 rules #32–33] |
| **C12** | **Colour is never the only signal** | WCAG 1.4.1. Pair colour with icon, label, pattern or position (✓/✗ on yes/no buttons). Test with a CVD simulator; roughly 1 in 12 men and 1 in 200 women have red-green deficiency (Shopify's article cites ~5% / 0.5%). | Charts, status, links, forms | Simulators approximate; test with real users when stakes are high. |

**Anti-generic checks for colour:** no default purple→blue gradient; no rainbow icon tiles; the accent appears in ≤ 3 places per viewport; one extra hue per page *only if* it has a job (data series, category code).
