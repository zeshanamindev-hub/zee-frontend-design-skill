# 12 · Visual & branding rules (B1–B10)
Token implementation: `../../mediums/web-ui/implementation.md`. Art directions: `../art-directions.md`.

| ID | Rule | How to apply | Honest caveat |
|---|---|---|---|
| **B1** | **Brand consistency** | Logo, colour roles, type, voice, imagery style and motion language are identical across pages, emails, socials and product. Use the client's **real assets** first (`../../workflows/asset-intake.md`). | Consistency ≠ rigidity; campaigns can flex inside rules. |
| **B2** | **Visual consistency** | Same radius family (e.g. 4/8/16 + full), one shadow scale (≤ 3 levels), one icon set (one stroke width), one illustration style, one photo treatment. | Mixing icon sets is the fastest way to look cheap. |
| **B3** | **Design token system** | Three layers: **primitive** (`--blue-600`) → **semantic** (`--color-action`, `--surface-raised`) → **component** (`--button-bg`). Code and design share names (Tailwind v4 `@theme`, shadcn variables, `theme.json`, Shopify settings). Colour priority from Detroit3D: brand accent → interactive → semantic → neutrals. | Too many tokens is as bad as none; start with ~40 semantic tokens. |
| **B4** | **Atomic design** (Brad Frost) | Atoms (button, input) → molecules (search field) → organisms (header) → templates → pages. Build and document bottom-up; review top-down. | A mental model, not a folder structure you must copy. |
| **B5** | **Design system principle** | One source of truth: tokens + components + usage guidelines + do/don't examples + accessibility notes; versioned; owned. | For a single small site, a style guide page + tokens may be enough (sprakdesign caution). |
| **B6** | **Visual rhythm** | Repeat and vary: alternate section densities (text-heavy → visual → data → quote), alternate container widths (full-bleed → contained → breakout), and keep a recurring motif (shape, line, texture). | Rhythm turns into a template if every page alternates identically. |
| **B7** | **Dominance principle** | Each composition has one dominant element (≈ 3× the visual weight of the next), sub-dominant elements, and subordinate details. Scale contrast of ≥ 3:1 between dominant and secondary sizes creates drama. | Two dominants fight; pick one. |
| **B8** | **Figure-ground** | Content (figure) must clearly separate from background (ground) through value contrast, edges, blur or depth. Busy backgrounds behind text fail. Use scrims, solid panels or a calm area of the image. | Glass/blur effects over busy content break figure-ground; test on real imagery. |
| **B9** | **Consistency over variety** | In **components and behaviour**, consistency wins every time. Variety belongs in **layout, scale and imagery** between sections (see the layout-variety rules in `layout-library.md`). | "Consistency over variety" applied to *layouts* creates the box-layout page users complain about. |
| **B10** | **Minimalism principle** | Remove what doesn't serve the job; keep personality through type, colour, imagery and one signature move. Minimal ≠ empty or generic. Run the deletion test: remove 30% of copy and every decorative element, then add back only what hurts to lose. | Pure minimalism is the most common route to "AI-generic". The signature move (`../anti-ai-slop.md` G3) is mandatory. |
